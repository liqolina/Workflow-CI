Langkah langkah me-running docker 

Windows PowerShell

1. Login docker
 
docker login

2. Run Docker

docker run -d `
  -p 8080:8080 `
  -e RUN_ID="5277b54484d04f7bb39a474a1df35179" `
  -e MODEL_NAME="Random_Forest" `
  --name "depression-model" `
  liqolina/workflow-ci:latest

3. Cek daftar kontainer Docker di mesin Anda

docker ps

4. Cek status Docker

curl http://localhost:8080/health
